# Bousy Player v0.5 — Verified progress, 2026-11-10

**Deliverable:** Source-only Android Studio/Gradle project. **No compiled APK.** Original Bousygram repository untouched. Based on v0.4 and its three-engine architecture.

## Changes made during this pass

1. **Engine-owner testability:** `PlayerSession` now supports a replaceable engine factory, preserving its production defaults, so tests can exercise the exact session logic without native binaries.
2. **Actual session behavior tests:** Added 14 compiled, runnable Kotlin checks for ownership/release order, handoff position, manual Pause, seek guards, background persistence, idempotent close, automatic native startup fallback and explicit-engine failure.
3. **Playback efficiency:** Media3 builds track display entries on track changes instead of on every 400ms status poll. LibVLC limits track enumeration to once per two seconds, with immediate invalidation after track selection.
4. **Android TV remote:** With controls hidden, Left/Right continue seeking in 10-second steps without snapping focus to the transport row; a brief on-screen status reports the new time or non-seekable condition.
5. **Subtitle visibility:** Media3 subtitle font fraction set to 0.06 of viewport height with embedded font size disabled. Native libVLC/mpv typography is unchanged pending device tests.
6. **Session scope:** Screen/UI focus effects now restart on a new `PlayerSession`; closed sessions ignore late manual switches and queue navigation.
7. **Android build readiness:** One `tools/build-and-qualify.sh` local/CI entry point and `tools/verify-apk.py` validate build, lint, unit tests and native ABI packaging (when an Android toolchain is available). Workflow supports `workflow_dispatch`, and artifact publication happens only on success.
8. **Model input tests:** Added 16 compiled Kotlin tests for HTTPS URL handling, HLS/DASH hints and time/seek constraints.

## Known limitations and next gates

- First obtain a real `testDebugUnitTest lintDebug assembleDebug` result. The CI job is only **configured**, not executed.
- Resolve any dependency/API compilation errors observed in Android CI; do not speculate about success.
- Inspect packaged native libraries for both ARM ABIs, then run device tests for native load order and `libc++_shared.so` compatibility.
- Test non-indexed `.ts` seeking, MKV HEVC/AC3, embedded/external subtitles, file-descriptor providers (including nonseekable cloud pipes), pausing while buffering, engine switching, first-frame performance and standby/HDMI audio behavior.
- A 1–2 GB ARM32 Android TV soak test is needed before calling this stable. The new track caching is a hypothesis about lower allocation pressure, not a measured performance result.
- Verify HTTPS redirect handling by native engines before enabling untrusted remote sources in a production release.
