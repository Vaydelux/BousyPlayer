# Bousy Player v0.7 — Development and qualification report

Date: 2026-11-10 (Asia/Manila)

## Outcome

Updated standalone Android player **source** package. It contains the Media3, libmpv and libVLC adapters, TV/phone responsive Compose player UI, playlists, local-file SAF selection, HTTPS/HLS/DASH entry points, subtitle/track controls, audio-focus policy, and local Continue Watching. Bousygram remains unchanged.

## Confirmed changes from v0.6

1. **Early engine-switch resume:** `PlayerSession.latestPosition()` preserves the pending persisted resume target when a still-preparing native decoder temporarily reports position zero. Once an authoritative timeline exists, the decoder's reported position takes precedence.
2. **Regression tests:** Three new actual-`PlayerSession` stub-integration checks cover early-switch resume, release ordering and Play intent.
3. **UI guard:** A source-level guard confirms compact Play/Pause calls toggle only once, hidden-HUD TV focus is available, and seekability handling remains. Existing v0.6 UI already had the single toggle; no UI change was required.
4. **Publishing:** Added a user-authenticated GitHub CLI script for creating `Vaydelux/BousyPlayer` without modifying Bousygram or overwriting an existing repository. CI artifact names now use v0.7.

## GitHub publication status

The connected GitHub repository lookup returned 404 for `Vaydelux/BousyPlayer`. The available connected GitHub actions cannot create repositories, so this source was not pushed. A guarded one-shot `tools/publish-to-github.sh` can create it under the authenticated user's identity using GitHub CLI on their computer. The workflow starts only after the repository is created and the project is pushed.
