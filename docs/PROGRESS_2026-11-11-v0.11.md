# Bousy Player v0.11 — Pause/focus-safe startup recovery

**Date:** November 11, 2026 (Asia/Manila)  
**Baseline:** v0.10 standalone Android source ZIP  
**State:** SOURCE PROTOTYPE. There is no verified Android Gradle build, APK, emulator or device playback result.

## Verified changes

1. **Startup timeout respects user interruptions:** `PlayerSession` resets its monotonic 20-second native startup window when an unconfirmed libmpv startup resumes from explicit Pause or a temporary audio-focus loss. Previously a 60–90-second interruption could trigger immediate Media3 fallback on resume.
2. **Fatal decoder cleanup:** On an unrecoverable playback error the session sends one best-effort Pause before abandoning audio focus; repeated polling does not repeatedly call Pause.
3. **One owner of Android TV Back:** `BackHandler` handles Back while the remote preview key handler no longer consumes raw `KEYCODE_BACK`, avoiding possible double-processing of a single press. This needs real TV verification.
4. **CI validation improved:** Source UI preflight guard added to GitHub Actions; release labels and publishing-script commit messages aligned to v0.11.
