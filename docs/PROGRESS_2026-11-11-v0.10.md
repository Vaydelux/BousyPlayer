## Changes implemented in v0.10

1. **User-requested retry after a fatal decoder error.** `PlayerSession.refresh()` now disarms an unrecoverable stale Play intent, so the main control presents Play instead of Pause. `PlayerSession.play()`/`retry()` explicitly release the failed engine, allocate a fresh engine and resume the latest acknowledged position. Error recovery never silently chooses a different engine when the user manually selected one.
2. **Bounded libmpv startup timeout for local AUTO MPEG-TS playback.** A native decoder can hang with neither frames nor error messages. `PlayerSession` tracks monotonic elapsed time through a test-injectable clock; after 20 seconds without a confirmed playable timeline, it can switch once from automatically selected libmpv to Media3. Manual engine selection, HTTPS sources, explicit Pause, focus suspension, successful native playback and already-attempted fallback are excluded. The 20-second rule is a heuristic and may be too aggressive for slow local/cloud document providers; device testing remains essential.
3. **Truthful, non-seekable controls.** The source now disables Restart/Start over and the visible ±10-second buttons when `PlaybackSnapshot.canSeek` is false, rather than presenting working-looking buttons that silently do nothing. D-pad hidden-HUD seeking continues to return honest “Not seekable” feedback.
4. **Build-time unit coverage.** Added a JUnit regression for all timeout-policy exclusions, alongside a CLI smoke harness that compiles the actual `PlayerSession.kt` with deterministic test engines.

### Acceptance gates before calling it stable

1. First successful Android Gradle compilation with genuine dependencies, including native mpv/VLC linker packaging.
2. Install/launch smoke check on ARM32 and ARM64 devices, and verify Android TV remote focus/Back.
3. Reproduce a 20-second stalled native MPV local TS source: verify one handoff only, no accidental retry after Pause, and correct position.
4. Test Play/Retry after a fatal VLC, MPV and Media3 failure; verify old engine is destroyed before replacement, audio focus is reacquired, and saved offset restored.
5. Test files with no seek index and unknown duration: visible seek controls disabled, no fabricated duration.
6. 2-hour memory/thermal soak on low-RAM Android TVs; subtitle/audio-track selection; MKV, M2TS, TS, MP4, HLS, DASH, SRT/VTT/ASS, E-AC3, and HEVC where available.
