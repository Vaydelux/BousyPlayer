# Bousy Player v0.12 — ARM ABI delivery milestone

Date: 2026-11-11. Repository: [Vaydelux/BousyPlayer](https://github.com/Vaydelux/BousyPlayer).

## Delivered in source
- Native-ABI splitting: one debug APK for `armeabi-v7a` and one for `arm64-v8a`, no universal APK.
- Per-APK validation: ZIP integrity, `classes.dex`, exactly one ABI, libmpv and VLC presence, ELF class and architecture (`EM_ARM=40`, `EM_AARCH64=183`).
- Synthetic validator regression tests for valid files, incorrect ELF machine and accidental cross-ABI packaging.
- Two named debug APK files uploaded to a private GitHub prerelease only after passing Kotlin unit tests, lint, APK assembly and validation.
- Updated README and qualification matrix to reflect the real successful v0.11 build, not the earlier source-only status.

## Evidence
- v0.11 baseline: GitHub Actions [#8](https://github.com/Vaydelux/BousyPlayer/actions/runs/42982351716) PASS; universal debug APK 306,065,705 bytes.
- v0.12: verify the triggered GitHub Actions run and its two attached APKs. Any new output size or PASS status must come from the actual run, not source assumptions.

## Not yet qualified
ARM32/64 physical installs, MKV/TS demuxer behavior and seek reliability, TV focus, subtitle readability, audio-focus interactions, native C++ runtime loading and low-RAM endurance. The build produces *debug testing packages*, not a production release.
