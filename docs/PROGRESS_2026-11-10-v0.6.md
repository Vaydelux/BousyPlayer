# Bousy Player v0.6 — Verified progress (2026-11-10)

**Artifact:** source-only Android Studio/Gradle project. Original Bousygram untouched. **No APK compiled.**

## Implemented this pass

1. **End-of-file audio focus cleanup.** `PlayerSession.refresh()` abandons focus, disarms Play intent and persists progress on a confirmed ended state. The focus coordinator's production implementation is unchanged.
2. **Correct Retry position after startup failure.** `PlayerSession` saves the selected resume offset before building the engine. Retry uses the last attempted offset when no authoritative native progress is available.
3. **Surface-aware native startup.** LibVLC no longer calls native Play before a valid video surface attaches. libmpv defers `loadfile` until its `SurfaceView` is attached. They preserve explicit Pause intent, while keeping file descriptors open for native playback lifetime.
4. **Bounded asynchronous local-startup fallback.** If AUTO selects libmpv for a local content URI and an error arrives before a native timeline becomes ready, `PlayerSession` releases MPV and attempts Media3 exactly once, at the original position. No automatic fallback for explicit engine selections or network sources.
5. **Android adapter smoke harness.** Added a Kotlin CLI harness that compiles the actual `MpvEngine.kt` and `VlcEngine.kt` against fake Android/native SDK signatures and simulates surface creation. Verifies that decoding does not start before a surface, starts on attachment, and VLC does not resume after the user pauses. **This is not native execution or full API validation.**
6. **CI and local checks.** `tools/check-source.sh` includes session, model and native-adapter smoke checks. CI debug artifact renamed to v0.6 and reports are uploaded on failure. Gradle versionCode/versionName updated.
