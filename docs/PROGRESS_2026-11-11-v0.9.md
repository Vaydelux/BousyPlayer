# Bousy Player v0.9 — Development and qualification report

**Project:** Standalone Android TV, phone and tablet media player inspired by Bousygram. **Baseline:** v0.8 source prototype. **Date:** 2026-11-11.

## Source code changes

| Area | Verified change | Regressions checked |
| --- | --- | --- |
| Relative seek while resume is pending | `PlayerSession.seekBy` uses `latestPosition()` (pending requested resume until acknowledged), rather than the provisional decoder `snapshot.position` | Saved 1:22 +10s yields 1:32, not provisional 0:02 +10s |
| Native startup recovery | `engineEverReady` requires an acknowledged timeline; native 0:02 playback before a saved 1:41 resume no longer suppresses one-time AUTO Media3 fallback after startup failure | Delayed decoder error after provisional progress successfully falls back, preserving 1:41 |
| Replay after EOF | Explicit Play from the ended state releases the previous engine and creates a new playback owner at 0:00 | Replay starts immediately with Play intention; release-before-load ordering holds |
| Completion tracking | `saveProgress` records duration as completed at EOF, even if last native TimeChanged was early | 4:20 reported progress with a 5:00 EOF records 5:00 completion |
| Audio focus after fatal error | `refresh()` abandons focus when the decoder has a fatal error and automatic fallback does not apply | Fatal non-fallback decoder error relinquishes focus |
| CI integrity | Version and artifact naming checks run before Android Gradle; XML and external VIEW filters are parsed in CI | Source release metadata check and YAML parsing |

## Android build/CI blocker

There is no Android SDK or Gradle executable installed in this runtime. `bash tools/build-and-qualify.sh` exits before any Android compile. The dedicated GitHub repository `Vaydelux/BousyPlayer` was not available during the previous repository checks and the connected GitHub tools do not expose creation of a new repository. The project includes publishing scripts and `.github/workflows/android.yml` to attempt the Android build once a repository is created.

**Actual APK:** Not produced. **Android Gradle build:** Not run. **ARM32/ARM64 device qualification:** Not run. **Production release:** Not qualified.
